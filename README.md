# Simple Line Editor in C

## About the Project

This project is a simple command-line line editor
developed using the C programming language.

It allows users to create, view and modify a text
document using simple menu-driven commands.

## Features

1. Display Document
2. Insert Line
3. Delete Line
4. Save File
5. Load File
6. Search Word

## Technologies Used

- C Programming Language
- VS Code
- GCC Compiler

## Data Structure

The project uses a 2D character array to store
multiple lines of text.

Maximum number of lines: 100
Maximum characters per line: 200

## How to Compile

gcc line_editor.c -o editor

## How to Run

editor.exe
